# Disease dataset
* URL adress: https://data.mendeley.com/datasets/k36wnd6knb/1 
* License: CC BY 4.0
* Cite dataset: chelangat, specioza; Anirwoth, Racheal; Mayanja, Kizito Najib; sserwadda, Abubakhari (2025), “A Machine  Learning Dataset for Classification of Common Coffee Leaf Diseases in Uganda. ”, Mendeley Data, V1, doi: 10.17632/k36wnd6knb.1
* Dataset size: 24.8 MB
* Limits: 
    - coffee wilt disease not covered but it is not so much of a problem for a local mount Elgon deployment as there is no Robusta plantation there which coffee wilt disease is mainly attacking in Uganda
    - only 2 diseases are covered: leaf rust and phoma
    - only leaves photo. Diseases on berries and stems are not represented.
    - pests, nutrient and water are also not covered
